1. WHAT HAS BEEN IMPLEMENTED
--------------------------------------------------------------------------------
A complete, standalone, production-grade Nearby Neurologists Finder module 
tailored for NeuroScope 3D (a brain tumour research and 3D visualization platform).

Core Capabilities:
- Entry Point Button: "Find Nearby Neurologists" (FindNearbyNeurologistsButton) 
  styled to match NeuroScope 3D medical-tech aesthetics.
- Geolocation & Search: Explicit "Use My Current Location" button (requests browser
  GPS coordinates only upon user click) with graceful permission-denial fallback, 
  plus manual address/city/ZIP geocoding search.
- Search Radius Selector: 5 km, 10 km (default), and 25 km with clear visual indicator.
- Google Rating Ranking: Results automatically sorted by highest Google rating first,
  with reviewCount tie-breaking. Unrated results are clearly distinguished and 
  placed after rated listings.
- Specialty & Category Integrity: Differentiates Neurologists (physicians), 
  Neurology Clinics, Hospitals/Medical Centers, Diagnostic Centers, and Neurosurgeons.
  Never conflates surgical neurosurgeons with medical neurologists.
- Strict Medical Ethics & Fee Rules: Never fabricates qualifications, degrees, or
  experience. Consultation fees display "Consultation fee not publicly available." 
  unless an official verified fee schedule is published.
- Dedicated Two-Column Provider Details: Left column contains verified doctor/clinic 
  information and notices; right column displays an interactive Google Map with 
  markers, route calculation, and a "Get Directions" navigation button.
- Dual Mode Support: Seamless switching between Live Google Places API and a 
  curated Demo Data Mode for local UI testing without Google API quotas.
- Backend Express Proxy: Optional proxy (server/index.ts) to keep API secrets server-side
  and bypass browser CORS constraints when querying Google Places Web Services.


2. ENTRY COMPONENTS AND ROUTES
--------------------------------------------------------------------------------
Primary Reusable Exports (available from 'src/index.ts'):
- FindNearbyNeurologistsButton: Entry CTA button to place in Navbar, Hero, or Reports.
- NearbyNeurologistsModule: Main discovery module with search, radius, filters, & cards.
- NeurologistDetails: Two-column detail view with interactive map.
- NeurologistCard: Individual doctor/clinic result card.
- GoogleMapView: Interactive map view with provider marker, user origin, & route.
- RadiusSelector: Accessible 5 km / 10 km / 25 km radius picker.
- DisclaimerBanner: Medical and demo data alert notices.

Registered Demo Routes in App.tsx:
- Route "/"                     -> Host Showcase page demonstrating button & module.
- Route "/nearby-neurologists"  -> Dedicated full-page route for directory search.
- Route "/nearby-neurologists/:providerId" -> Dedicated route for individual doctor details.

5. REQUIRED ENVIRONMENT VARIABLES
--------------------------------------------------------------------------------
In client-side environment (.env or .env.local):
- VITE_GOOGLE_MAPS_API_KEY=your_google_maps_api_key_here
  (or NEXT_PUBLIC_GOOGLE_MAPS_API_KEY if integrating into Next.js)

In server-side environment (if using backend proxy):
- GOOGLE_MAPS_API_KEY=your_google_maps_api_key_here
- PORT=5001


6. REQUIRED GOOGLE CLOUD APIS AND SETUP
--------------------------------------------------------------------------------
1. Enable the following APIs in Google Cloud Console:
   - Maps JavaScript API
   - Places API (or Places API New)
   - Geocoding API
   - Directions API
2. Billing must be enabled on the Google Cloud project.
3. Configure API key restrictions:
   - Client key: HTTP referrer restrictions (e.g., https://your-domain.com/*)
   - Server key: IP address restrictions.


7. BACKEND / API ENDPOINTS
--------------------------------------------------------------------------------

- GET /api/places/details?placeId=... -> Google Places Details

10. KNOWN LIMITATIONS
--------------------------------------------------------------------------------
- Live Google API calls require active Google Cloud billing credentials; without a key,
  the module defaults to Demo Data Mode.
- Google Places Web Service enforces CORS on direct browser fetch; using the provided 
  Express proxy or Next.js route handlers is required for server-side place queries.
- Headless browser automation via Playwright was prevented due to upstream Azure Edge CDN 
  driver 404; DOM and component interaction testing was verified via jsdom and Vitest.
